# Security policy

Trail Advisor is a public static demo and does not operate a server-side account or location database. It still handles browser input and contacts public services.

If you discover a security issue, please do not include sensitive details in a public issue. Use GitHub's **Report a vulnerability** option in the repository Security tab if it is enabled. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and request a private channel. Include affected page/commit, impact, and safe reproduction steps. Do not submit private location data or credentials.

There is no guaranteed response time or formal support commitment for this portfolio project.
